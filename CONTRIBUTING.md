# Contribuindo

Obrigado por ajudar a melhorar o MKV Tool by Tokon!

1. Abra uma *Issue* descrevendo o problema ou a sugestão.
2. Para alterações, crie um *fork* e uma branch separada.
3. Envie um *Pull Request* explicando as mudanças e como foram testadas.
4. Não envie vídeos, arquivos MKV pessoais, chaves, senhas ou configurações privadas.
5. Para relatar bugs, informe a versão do Windows, Python, MKVToolNix e uma descrição reproduzível (sem dados pessoais).

Antes de enviar alterações, execute `python -m py_compile MKVTool.py` e, se possível, teste a interface e o processamento em arquivos de amostra no Windows.
